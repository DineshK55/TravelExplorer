# TripAdvisor Clone

A modern and responsive TripAdvisor-inspired travel website built using HTML5, CSS3, Flexbox, and CSS Grid.

## Live Preview

Explore destinations, hotels, restaurants, and activities through a clean and modern travel website interface.

---

## Features

* Responsive Design
* Sticky Navigation Header
* Hero Banner Section
* Search Bar
* Destination Filters
* Featured Destinations
* Popular Hotels
* Top Rated Restaurants
* Things To Do Section
* Travel Statistics
* Newsletter Subscription
* Social Media Footer
* Hover Animations
* Card Effects
* Smooth Scrolling
* Mobile Friendly Layout

---

## Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Font Awesome Icons
